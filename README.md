AI-Based Dynamic Congestion Control System
Real-Time Traffic Monitoring: Uses AI models to analyze live traffic data from cameras, sensors, or crowdsourced input.

Dynamic Signal Adjustment: Adjusts traffic light durations based on congestion levels to reduce wait time and bottlenecks.

Decentralized Decision Making: Each junction uses local AI logic for faster response, reducing dependency on a central server.

Heatmap Visualization: Displays real-time congestion levels on a city map for drivers, planners, and emergency services.

Reinforcement Learning Optimization: Learns optimal signal timings over time through continuous feedback and rewards.

Scalable and Open: Modular design makes it easy to integrate with smart city APIs, simulations, or real-world data pipelines.

Federated Learning Integration: Enables decentralized model training across multiple traffic nodes without sharing sensitive data, improving privacy and scalability.
